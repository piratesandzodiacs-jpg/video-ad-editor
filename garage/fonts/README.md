# خطوط العناوين

- `Anton.ttf`: الكلمة الكبيرة بالعناوين. حقوق: The Anton Project Authors، رخصة SIL OFL 1.1 (`OFL-Anton.txt`).
- `Poppins-Bold.ttf`: السطر الصغير. حقوق: The Poppins Project Authors، رخصة SIL OFL 1.1 (`OFL-Poppins.txt`).

الرخصة OFL تسمح بالاستخدام والتوزيع مع بقاء ملف الرخصة معهم. الملفات تحوّلت من WOFF (حزمة fontsource على npm) إلى TTF بدون تغيير بالتصميم. `garage/get_fonts.sh` يعيد توليدها لو احتجت.
